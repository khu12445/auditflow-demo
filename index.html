QUALITY GATES

What stays under human control

✓ Financial entries should be reviewed before posting when accuracy or source evidence is uncertain.
✓ OCR or LLM extracted fields need checks against the actual PDF and line totals.
✓ Bank-only data must not be presented as a complete accrual accounting system.
✓ Client data should never be bundled into a public portfolio demo.
